📦 平台迁移

LobsterAI → Hermes Agent

完整迁移原有自动化体系：记忆系统、定时任务、饮食追踪、股票推送、信用卡检查。从零搭建到全部跑通。

飞书 Base 饮食管理

接入飞书多维表格作为健康数据中心，包含饮食记录、减脂计划、公司菜单三张表。支持手动记录 + 定时提醒。

  • 饮食表：热量、蛋白质、碳水、脂肪自动计算
  • 计划表：每天三餐推荐 + 热量目标
  • 菜单表：公司食堂菜品的完整数据库

🎨 飞书交互卡片

所有推送从纯文本升级为飞书交互卡片（interactive message card），统一 wathet 色调，字段分列排版，底部带操作链接。

  • 饮食卡片：三餐分列 + 热量汇总 + 追踪入口
  • 股市卡片：三指数并排 + 热点板块 + AI 评论
  • 配色定制：🔴涨 🟢跌（中国股市习惯）
  • 轻断食日专属样式

📈 A股监控

基于 yfinance 实时拉取上证、深证、创业板三大指数，午间 + 收盘两次推送。

  • 点位 & 涨跌幅实时显示
  • 当日领涨/领跌板块自动抓取
  • AI 生成 1-2 句市场评论
  • 配色遵循 A 股习惯：红涨绿跌

💳 信用卡智能检查

每天 08:30 自动检查：

  • 读 Things 3 Today 待办 → 识别需关注的银行
  • 查阿里云邮箱账单 → 提取金额和到期日
  • 有账单 → 推送还款提醒卡片
  • 无账单 → 自动清理过期待办

覆盖：工行、交行、招行、光大、中信、平安、广发

🍽️ 饮食追踪

减脂计划：周一/四轻断食 800kcal · 周二/三/五正常 1500kcal · 周六 1600kcal · 周日 1500kcal

记录方式：口头告诉 Hermes → 自动写入飞书 Base → 推送汇总卡片

拍照识别：支持食物拍照 → qwen-vl-max 视觉识别 → 自动估算热量（开发中）
